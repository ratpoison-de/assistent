# Assistent – Web-App (responsiv)

Die Web-Version des **Assistent** von Thorsten von Plotho-Kettner: Woche, Kalender, Pinnwand und Wetter in einer App.

**Öffnen:** https://ratpoison-de.github.io/assistent/

## Abgleich
Handy-App (Android), Windows-App und diese Web-App gleichen sich über das **private** Repo `assistent-daten` ab.
Beim ersten Öffnen fragt die App nach einem GitHub-Token (Fine-grained, nur `assistent-daten`, *Contents: Read and write*).
Der Token bleibt nur im jeweiligen Browser bzw. Gerät gespeichert.

In diesem öffentlichen Repo liegt nur der Programmcode – keine Daten.

## Hinweise
- Gmail läuft nur in der Android-App; am PC öffnet der Mail-Bereich Gmail im Browser.
- Google-Kalender-Termine schickt das Handy als Kopie mit; am PC sind sie zum Ansehen da.
- Im Browser über das Menü „App installieren“ lässt sich die Web-App wie ein Programm anlegen.
